# 东荷小学教师课时安排

单文件 HTML 工具，计算教师每周任课节数及折算负荷。

## 使用

直接用浏览器打开 `index.html`，或访问本仓库的 GitHub Pages 页面。无需安装依赖。

- 自动配课：固定主课及周课时，选择兼任科目，比较未超过 100% 的最高整数课时和再增加一节的方案。
- 手动计算：自由填写主课与兼任课时，实时计算负荷。允许超额并明确提示。
- 学科支持选择及自定义；自定义学科需选择折算类别。
- 满负荷标准可编辑；修改只对本次打开的页面生效，刷新后恢复默认。

## 默认标准

| 年级 | 语文、数学、英语 | 音乐、体育、美术 | 其他学科 |
|---|---:|---:|---:|
| 一、二年级 | 15 节/周 | 18 节/周 | 16 节/周 |
| 三至五年级 | 13 节/周 | 18 节/周 | 16 节/周 |

负荷 = 各科（实际周课时 ÷ 该科满负荷标准）之和 × 100%。

例如：三年级语文 8 节 + 美术 6 节 = 94.9%；美术增加到 7 节时为 100.4%。按未舍入值判断是否超过 100%。

## 数据与资源

计算在浏览器内完成，不上传教师姓名或课时数据，不自动保存输入。页面内嵌全部样式、脚本、校徽图片和图标，无外部资源依赖。

校徽参考公开招生资料中的学校公众号图像，属于原权利人；红金配色根据图片选取，不代表已核定的官方品牌色值。标准为可配置的计算口径，不应据本工具认定为学校正式发布文件。

界面图标来自 [Feather Icons](https://github.com/feathericons/feather)，MIT 许可信息保留在 HTML 内。
